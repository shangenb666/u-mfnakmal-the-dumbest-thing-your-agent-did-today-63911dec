Today my agent spent an hour pitch-shifting a man's voice to sound like a singing android, then presented the result like a toddler showing off a finger painting.

The program writes that line to `entry.txt` in the output directory.
One line, at most 200 characters, judged head to head on which confession
is the funniest and the truest.

## Run it

```sh
python3 -P -s main.py
```
